# تطبيق مياه اسكاكا (PWA)

محتويات المجلد:
- `index.html` — التطبيق (واجهة جوال + كل البيانات والمنطق الأصلي)
- `manifest.webmanifest` — بيانات التطبيق (الاسم، الأيقونات، الألوان)
- `sw.js` — يجعل التطبيق يعمل بدون إنترنت (الواجهة + الخرائط التي سبق عرضها)
- `icons/` — الأيقونات

## التشغيل والتثبيت
1. ارفع المجلد كاملاً إلى استضافة تعمل بـ HTTPS (GitHub Pages أو Netlify أو Cloudflare Pages أو أي استضافة).
   HTTPS مطلوب لتحديد الموقع (GPS) ولعمل التثبيت.
2. افتح الرابط من الجوال:
   - أندرويد (Chrome): القائمة ← «تثبيت التطبيق»، أو زر «تثبيت التطبيق على الجهاز» داخل تبويب «المزيد».
   - آيفون (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

## ملف APK لأندرويد
بعد رفع الموقع، ضع رابطه في https://www.pwabuilder.com واختر Android لتحصل على ملف APK/AAB جاهز للتثبيت أو النشر على Google Play.

## ملاحظات
- المواقع المحفوظة تُخزَّن على الجهاز نفسه (localStorage)، ويمكن تصديرها CSV / JSON / تقرير.
- صور الخرائط تحتاج إنترنت، والمناطق التي شاهدتها سابقاً تُحفظ مؤقتاً (حتى 300 صورة).
